DDW AI Hub · 第十八篇 12 项架构补充

v5.3 生产就绪 · 纯平台设计
§18.1租户隔离中间件core/middleware/tenant.py
问题
单租户架构无法多企业共用实例
设计
JWT → TenantMiddleware → contextvars → ORM TenantMixin → 自动过滤 tenant_id
关键
家庭版 tenant_id="default"；SME 启用多租户后 ORM 自动隔离
§18.2EventBus 插件间通信core/events/event_bus.py
问题
插件互相不知道对方存在，无法通信
设计
进程内 Pub/Sub（单 Worker）→ 多 Worker 降级 Redis Pub/Sub；manifest 声明 events
关键
异常隔离 · 优先级排序 · 通配符 record.* · 最近 N 条追踪
§18.3版本依赖冲突检测core/plugin_manager/dependency_resolver.py
问题
插件 A 依赖 kb≥2.0，B 依赖 kb<2.0，冲突
设计
SemVer 约束求解 + 有向图拓扑排序检测循环依赖 + 管理后台告警
关键
安装时自动检测；支持 ~= / != 等运算符
§18.4水平扩展方案core/scaling/worker_config.py
问题
50+ 用户时单 Worker 变瓶颈
设计
Caddy/Nginx 反代 → 多 FastAPI Worker → Redis Pub/Sub 替代 EventBus → 共享 PG/Cache
关键
DDW_WORKERS=N 启用；sticky session 保 SSE；家庭版保持单 Worker
§18.5配置热更新core/reload/hot_reload.py
问题
切换 SQLite ↔ PG / 缓存 ↔ Redis 需重启
设计
POST /admin/reload → EngineFactory 原子替换连接池 → 旧请求用旧引擎，新请求用新引擎
关键
asyncio.Lock 防并发；连接失败回滚
§18.6API 版本化core/api_versioning/version_router.py
问题
破坏性 API 变更导致客户端故障
设计
/api/v1/ /api/v2/ 前缀；废弃 API 返回 Deprecation 头；6 个月保留期
关键
API_VERSIONS 元数据；版本信息端点
§18.7插件进程沙箱core/plugin_manager/sandbox.py
问题
第三方插件 bug/恶意代码影响主进程
设计
manifest isolation: process → 子进程 JSON-RPC 2.0；资源限制（内存/CPU/超时）
关键
受信任插件不隔离；第三方插件必须在沙箱里跑
§18.8插件级配置manifest.yaml config · sdk/config_manager.py
问题
每个插件配置项硬编码不可维护
设计
manifest config.groups + config.items 声明 schema；管理后台自动生成表单；system_configs 表
关键
get_config("key") 读取；支持 int/str/bool/enum；变更回调
§18.9插件市场协议core/marketplace/registry.py
问题
第三方插件缺少标准化发布安装流程
设计
.ddwplugin 包（tar.gz + manifest + 代码 + 签名）；注册表 API；SHA256 校验
关键
本地模式（文件系统注册表）；远程模式（REST API）
§18.10插件付费许可core/licensing/license_manager.py
问题
第三方插件需要定价授权模型
设计
manifest pricing 段（free/one_time/subscription）；底座加载时校验 License
关键
License 与 tenant_id 绑定；支持试用期
§18.11国际化 i18nsdk/i18n.py · locales/*.json
问题
插件面向不同语言用户
设计
locales/zh-CN.json / en-US.json；t() 函数；语言从 JWT 或浏览器获取
关键
支持 {date} {time} 占位符；回退至默认语言
§18.12插件测试框架sdk/testing/fixtures.py
问题
插件开发者缺少标准化测试工具
设计
ddw_test_app fixture：内存 SQLite + Mock LLM/EventBus/IM + AsyncClient；多 Fixture（db_user/plugin_token）
关键
pytest.ini 配置；覆盖率支持；CI 友好
