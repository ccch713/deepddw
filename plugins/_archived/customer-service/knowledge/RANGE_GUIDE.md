# 客服知识库范围说明

## 重要：知识库内容选择指南

本插件的知识库范围直接影响 AI 客服的回答质量和安全性。请仔细阅读以下说明。

---

## ✅ 推荐放入知识库的内容

### 1. 公开产品信息
- 产品功能介绍
- 服务范围说明
- 公司简介和团队介绍
- 成功案例（脱敏后）
- 行业解决方案概述

### 2. 常见问题 (FAQ)
- 如何开始合作
- 服务流程说明
- 技术支持联系方式
- 常见问题解答

### 3. 公开文档
- 产品手册（公开版）
- API 文档（公开接口）
- 使用指南
- 最佳实践

### 4. 价格信息（可选）
- 公开的价格套餐
- 服务等级说明
- 付费方式

---

## ❌ 不应放入知识库的内容

### 1. 核心技术机密
- 算法实现细节
- 模型训练数据
- 内部技术参数
- 源代码

### 2. 商业敏感信息
- 客户名单
- 合同细节
- 成本结构
- 利润率

### 3. 内部流程
- 内部审批流程
- 员工手册
- 内部培训材料

### 4. 定价策略（如果不想公开）
- 折扣政策
- 特殊报价
- 成本价

---

## ⚠️ 安全注意事项

### 1. 数据脱敏
在将内容放入知识库之前，请确保：
- 客户名称已脱敏（使用"某客户"代替）
- 具体数字已模糊化（使用"约XX"代替）
- 内部代号已移除

### 2. 访问控制
- 知识库文件应设置适当的文件权限
- 不要将知识库目录放在公网可访问的位置
- 定期审查知识库内容

### 3. 对话监控
- 建议开启对话日志记录
- 定期检查异常对话模式
- 设置频率限制防止滥用

## 📝 知识库文件格式

### Markdown 格式 (推荐)
```markdown
# 产品介绍

## 功能特性
- 特性1：...
- 特性2：...

## 使用场景
...
```

### YAML 格式
```yaml
product:
  name: "产品名称"
  features:
    - "特性1"
    - "特性2"
  faq:
    - question: "问题1"
      answer: "答案1"
```

### JSON 格式
```json
{
  "product": {
    "name": "产品名称",
    "features": ["特性1", "特性2"]
  }
}
```

### 1. 文件组织
```

├── products/          # 产品信息

│   └── faq.md

    └── about.md
```

### 2. 内容更新
- 定期审查知识库内容
- 删除过时信息
- 添加新内容
- 保持内容准确性和时效性

### 3. 质量控制
- 内容应简洁明了
- 避免歧义表述
- 提供具体示例
- 保持一致的风格

## 🛡️ 防护措施

### 1. Prompt 防护
在知识库中添加以下规则：

```markdown
# 客服回复规则

1. 只根据提供的知识库内容回答，不要编造信息
2. 如果知识库中没有相关信息，请说明"抱歉，这个问题我需要转接人工客服"
3. 回答要简洁、专业、友好
4. 不要泄露敏感信息（价格细节、技术参数、内部流程等）
5. 每次回答控制在 200 字以内
```

### 2. 频率限制
- 同一 IP 每天最多 20 次对话
- 同一会话最多 50 轮对话
- 异常模式自动告警

### 3. 内容过滤
- 过滤敏感关键词
- 检测异常提问模式
- 自动转接人工客服
