# DDW SPC Basic Plugin

Statistical Process Control foundation for quality management.

## Features
- **Control Charts**: I-MR, Xbar-R, Xbar-S
- **Process Capability**: Cp, Cpk, Pp, Ppk calculation
- **Nelson Rules**: Automated violation detection (8 rules)
- **AI Interpretation**: Natural language explanation of SPC results
- **Capability Grading**: A/B/C/D grading system
