# DDW CAPA Workflow Plugin

Full lifecycle management for Corrective and Preventive Actions.

## Features
- **CAPA Creation**: Auto-numbered CAPA records with source tracking
- **State Machine**: open → investigation → action → verification → closed
- **Root Cause Analysis**: Support for 5-Why and fishbone methods
- **Audit Trail**: Complete history of all status changes
- **Overdue Alerts**: Automatic escalation tracking
- **Statistics**: Dashboard-ready CAPA analytics
