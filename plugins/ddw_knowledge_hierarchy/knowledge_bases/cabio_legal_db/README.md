## 使用说明

1. **客户审厂准备**：使用01-08号法规文件回答合规性问题
2. **质量问题处理**：使用09-12号工具处理投诉和偏差
3. **供应商管理**：使用15+17号文件管理供应商
4. **AI知识库演示**：向客户展示DDW AI底座平台的知识检索和文档生成能力

## 数据来源说明

本知识库内容来源于公开的法律法规文本、国家标准、国际标准和行业通用模板。在实际业务中，请以正式发布的法规文本和客户提供的具体要求为准。
