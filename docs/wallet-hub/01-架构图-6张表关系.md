## 一、6 张表速览

| # | 表名 | 用途 | 主键 |
|---|---|---|---|
| 1 | `dw_wallet_accounts` | 钱包账户（每个用户一行） | id (auto) |
| 2 | `dw_wallet_recharge_orders` | 充值订单（微信/支付宝） | id (auto) |
| 3 | `dw_wallet_charge_records` | 扣费流水（按量消费） | id (auto) |
| 4 | `dw_wallet_refund_records` | 退款记录（原路退回） | id (auto) |
| 5 | `dw_wallet_royalty_records` | 分成记录（课件作者收益） | id (auto) |
| 6 | `dw_wallet_rate_rules` | 计费规则（单价表） | id (auto) |

**全部金额字段**：`Integer`（单位：分，禁止 Float）。
**用户标识**：`String(64)`（不是 int），即 `user_id` 是字符串。
**独立 Base**：`WalletBase`，不依赖平台租户体系（无 tenant_id 字段）。

## 四、关键发现（评估）

| # | 发现 | 影响 |
|---|---|---|
| 1 | **无外键约束** | 数据库层不强制一致性，靠应用层维护；并发场景需谨慎 |
| 2 | **user_id 是 String(64)** | 问渠的 user_id 是 BigInteger——不能直接复用 |
| 3 | **`version` 乐观锁** | account.py 用原生 SQL `UPDATE ... WHERE version=:ov` 实现，5 次重试——并发扣费安全 |
| 4 | **`frozen_cents` 字段未使用** | 预留冻结金额字段，但代码中无任何读写 |
| 5 | **`trigger_txn_id UNIQUE`** | 分成幂等设计良好；同一笔扣费不会重复分账 |
| 6 | **`notify_raw Text`** | 微信回调原始报文落库，可对账/重放——审计友好 |
| 7 | **`balance_after` 记录扣后余额** | 流水带余额快照，无需查 account 即可渲染对账单 |
| 8 | **`server_default=func.now()`** | 时间字段由 DB 生成，避免 Python/DB 时区漂移 |

## 五、支付链路（5 个端点 + 4 张流水）

```
用户扫码 → POST /recharges
   ↓ (create_recharge)
   ├→ INSERT dw_wallet_recharge_orders (status=pending)
   ├→ 调微信 Native 下单
   └→ 返回 code_url
   ↓
用户支付完成
   ↓
微信回调 → POST /recharges/notify/wechat
   ↓ (handle_wechat_notify)
   ├→ SELECT FOR UPDATE order (SELECT ... WHERE order_no=:ono)
   ├→ 金额核对 (paid_amount vs amount_cents)
   ├→ UPDATE orders SET status='paid' WHERE status='pending' (原子)
   ├→ credit_balance() → UPDATE accounts SET version+=1 WHERE version=:ov
   └→ INSERT ChargeRecord? NO → INSERT? Actually NO 一笔记录
       (ddw_wallet 充值入账只加余额，不写 charge_records)

用户消费 → POST /charges
   ↓ (charge)
   ├→ SELECT charge_records WHERE ref_id=? (幂等)
   ├→ debit_balance() → 乐观锁扣减
   └→ INSERT charge_records (balance_after 快照)

用户提现/退款 → POST /refunds
   ↓ (refund_balance)
   ├→ SELECT 最近一笔 recharge_orders
   ├→ debit_balance()
   ├→ INSERT refund_records
   └→ ⚠️ 仅记录，未实际调微信退款 API（注释 L76-77）

课件消费 → 自动分成 → POST /royalties
   ↓ (settle_royalty)
   ├→ SELECT royalty_records WHERE trigger_txn_id=? (幂等)
   ├→ 按学科计算 rate (英语 50%, 其他 80%)
   ├→ credit_balance() → 作者账户
   └→ INSERT royalty_records

流水查询 → GET /transactions
   ↓ 4 张表 union → 按时间倒序 → 分页
```
