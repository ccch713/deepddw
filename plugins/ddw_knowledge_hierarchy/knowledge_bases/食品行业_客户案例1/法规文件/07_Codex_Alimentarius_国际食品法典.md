# Codex Alimentarius 国际食品法典

> 国际食品法典委员会（Codex Alimentarius Commission）制定的国际食品标准，是贵公司产品出口的重要参考依据。

---

## 一、Codex Alimentarius 概述

### 1.1 组织背景

- **全称**：国际食品法典委员会（CAC）
- **成立**：1963年，由FAO和WHO联合设立
- **成员**：189个成员国和1个成员组织（欧盟）
- **目标**：保护消费者健康，确保食品贸易公平

### 1.2 核心原则

- 基于科学证据和风险分析
- 透明、包容、共识
- 与WTO/SPS协定协调

## 二、与贵公司相关的Codex标准

### 2.1 CAC/GL 1-1979（Rev.2019）预包装食品标签通用标准

- 食品名称、配料表、净含量、保质期、贮存条件
- 营养标签要求
- 过敏原声明

### 2.2 CODEX STAN 192-1995 食品添加剂通用标准

- 食品添加剂的定义和分类
- 允许使用的食品添加剂清单
- 使用条件和限量

### 2.3 CXC 1-1969（Rev.2020）食品卫生通则

- HACCP原理的国际参考文件
- 食品生产全过程的卫生要求
- 七大原理和实施指南

### 2.4 CAC/RCP 1-1969（Rev.2003）附件——HACCP体系应用指南

- HACCP体系的详细实施指南
- 与贵公司HACCP体系直接相关

## 三、婴幼儿配方食品相关Codex标准

### 3.1 CODEX STAN 72-1981 婴儿配方食品标准

- 营养成分要求（蛋白质、脂肪、碳水化合物、维生素、矿物质）
- 污染物限量
- 微生物要求
- 标签和声称规定

### 3.2 CODEX STAN 73-1981 罐装婴幼儿食品标准

- 适用于较大婴儿和幼儿的罐装食品

### 3.3 CAC/GL 10-1979（Rev.2009）婴幼儿喂养指导原则

- 母乳喂养推广
- 配方食品的合理使用指导

## 四、食品添加剂相关Codex标准

### 4.1 CODEX STAN 192-1995 中的ARA/DHA相关条款

- ARA（花生四烯酸油脂）作为食品添加剂的使用条件
- DHA（二十二碳六烯酸油脂）作为食品添加剂的使用条件
- 在婴幼儿配方食品中的允许使用范围和限量

## 五、WTO/SPS协定与Codex的关系

- WTO卫生与植物卫生措施协定（SPS）将Codex标准作为国际参考
- 符合Codex标准的产品在国际贸易中享有有利地位
- 成员国可以采用更严格的标准，但需基于科学证据
