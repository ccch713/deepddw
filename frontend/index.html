由 DDW AI Hub 6.0 裁剪而来的开源一体包：DSH 引擎 · SQLite 知识库 · 轻量记忆 · 网关 Token 门禁 · MCP 双协议（streamable-http + 经典）。无账号体系，静态访问 Token 即全部门禁。

🛡️

Token 门禁

全部 MCP 端点与网关 API 过静态访问 Token（Bearer / X-DDW-Token），缺失或无效即 401；工具按白名单分层过滤，商业插件工具绝不注册。

🔌

MCP 双协议

streamable-http（2025-03-26）与经典端点（2024-11-05）双轨并存，工具集合一致；FastMCP 在插件加载完成后重建，插件工具为真实实现。

📚

知识库 + 记忆

SQLite 个人级知识库（FTS5/LIKE 检索）与轻量长期记忆，对话 / 检索 REST API + MCP 工具双入口；断网或存储故障自动降级，不阻塞主流程。

📱

手机浏览器 PWA

启动页填地址 + Token 过网关校验后进入工作台；Token 仅存本机会话，iframe 内不携带明文 Token。一键加装桌面 / 主屏。

🔁

插件框架

PluginBase 装载框架 + 热加载运行时保留；插件目录只含白名单组件（ddw-docs-portal / ddw-searxng），可自行扩展。
