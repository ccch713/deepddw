# SPC统计过程控制 — 控制图与过程能力指数

> 本文件为贵公司提供SPC（Statistical Process Control）的完整参考，涵盖控制图类型、判异规则、过程能力指数计算和解读。

---

## 一、控制图类型与适用场景

### 1.1 计量型控制图（连续数据）

| 控制图 | 子组大小 | 适用场景 | 示例 |
|--------|---------|---------|------|
| **I-MR**（单值-移动极差） | n=1 | 连续过程、破坏性检测、检测成本高 | ARA含量单次检测 |
| **Xbar-R**（均值-极差） | n=2~9 | 产品特性测量、抽样检测 | DHA纯度批次检测 |
| **Xbar-S**（均值-标准差） | n≥10 | 大子组、数据量大 | 环境监测多点数据 |

### 1.2 计数型控制图（离散数据）

| 控制图 | 数据类型 | 适用场景 |
|--------|---------|---------|
| P图 | 不合格品率 | 检验合格率监控 |
| NP图 | 不合格品数（固定样本量） | 批次检验合格数 |
| u图 | 单位缺陷数（可变样本量） | 外观缺陷数 |
| c图 | 缺陷数（固定样本量） | 特定工序缺陷数 |

## 二、SPC八大判异规则

### 2.1 规则总览

| 规则编号 | 描述 | 信号含义 | 适用控制图 |
|---------|------|---------|-----------|
| 规则1 | 1个点落在A区（±3σ）以外 | 过程失控，存在特殊原因 | 所有 |
| 规则2 | 连续3点中有2点在A区（±2σ以外） | 过程偏移趋势 | I图、Xbar图 |
| 规则3 | 连续5点中有4点在B区（±1σ以外） | 过程均值偏移 | I图、Xbar图 |
| 规则4 | 连续9点落在中心线同一侧 | 过程均值偏移 | 所有 |
| 规则5 | 连续6点递增或递减 | 过程趋势（缓慢漂移） | 所有 |
| 规则6 | 连续14点中相邻点交替上下 | 分层异常（两台设备混用） | I图、Xbar图 |
| 规则7 | 连续15点落在C区（±1σ以内） | 过程变异减小或数据分层 | I图、Xbar图 |
| 规则8 | 连续8点落在中心线两侧C区以外 | 混合了两个不同过程 | I图、Xbar图 |

### 2.2 判异规则适用性

- **I图/Xbar图**：全部8条规则适用
- **MR图/R图/S图**：仅适用规则1、4、5、7（核心规则）
- **P图/NP图/C图/U图**：仅适用规则1、4、5、7

### 2.3 区域划分（Western Electric规则）

```
UCL (+3σ) ─── A区 (+3σ ~ +2σ)
             B区 (+2σ ~ +1σ)
CL  (0)    ─── C区 (+1σ ~ -1σ)
             B区 (-1σ ~ -2σ)
LCL (-3σ) ─── A区 (-2σ ~ -3σ)
```

## 三、过程能力指数

### 3.1 Cp — 潜在过程能力指数

**公式**：`Cp = (USL - LSL) / 6σ`

**含义**：在不考虑均值偏移的情况下，过程的潜在能力。

**解读**：
| Cp值 | 等级 | 评价 |
|------|------|------|
| Cp ≥ 2.0 | A级 | 过程能力充足（6σ水平） |
| 1.67 ≤ Cp < 2.0 | B级 | 过程能力良好 |
| 1.33 ≤ Cp < 1.67 | C级 | 过程能力尚可（4σ水平） |
| 1.0 ≤ Cp < 1.33 | D级 | 过程能力不足，需改进 |
| Cp < 1.0 | E级 | 过程能力严重不足 |

### 3.2 Cpk — 实际过程能力指数

**公式**：
```
Cpk = min(Cpu, Cpl)
Cpu = (USL - μ) / 3σ
Cpl = (μ - LSL) / 3σ
```

**含义**：考虑均值偏移后的实际过程能力。

**解读**：
| Cpk值 | 评价 | 行动 |
|-------|------|------|
| Cpk ≥ 1.67 | 过程能力充足 | 维持现状 |
| 1.33 ≤ Cpk < 1.67 | 过程能力良好 | 持续监控 |
| 1.0 ≤ Cpk < 1.33 | 过程能力尚可 | 需改进，加严检验 |
| Cpk < 1.0 | 过程能力不足 | 必须改进，全检或暂停 |

### 3.3 Pp — 过程绩效指数

**公式**：`Pp = (USL - LSL) / 6s`（s为长期标准差）

**与Cp的区别**：Pp使用全量数据的标准差，反映长期波动。

### 3.4 Ppk — 过程绩效指数

**公式**：`Ppk = min(Ppu, Ppl)`

**与Cpk的区别**：Ppk使用全量数据，反映长期实际绩效。

### 3.5 Cp与Cpk的关系

- **Cpk ≤ Cp**（永远成立，因为Cpk考虑了偏移）
- **Cp = Cpk**：表示均值恰好在规格中心
- **Cpk = 0**：表示均值恰好在规格边界上
- **Cpk < 0**：表示均值已超出规格限

### 3.6 食品行业应用要点

| 指标 | 食品行业典型应用 | 常见目标值 |
|------|----------------|-----------|
| ARA含量 | 花生四烯酸油脂中ARA比例 | Cpk ≥ 1.33 |
| DHA含量 | DHA藻油中DHA比例 | Cpk ≥ 1.33 |
| 微生物指标 | 沙门氏菌、大肠杆菌等 | 不得检出（Ppk无意义） |
| 水分活度 | 产品Aw值 | Cp ≥ 1.67 |
| 粒径分布 | 粉剂产品粒径 | Cpk ≥ 1.0 |
