## §B. 3 个文件的响应式缺陷（建议补 @media 断点）

**问题**: `ddw-agents.html` / `ddw-skills.html` / `ddw-hris.html` 没有 `@media` 断点，在 < 768px 屏幕上：
- 200px 固定宽度的 `.sidebar` 会挤占主内容区
- `.detail-layout` 的 `grid-template-columns: 280px 1fr` 在窄屏会折行难看
- `.app-footer` 三段水平排列会溢出

**缓解因素**:
- 三个文件都用了 `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))` 这种**自适应布局**作为主网格（卡片网格本身能响应）
- `viewport` meta 已设
- 业务场景上这三个是企业内部控制台（OA 后台），目标用户大概率在 PC 端访问

**修复建议**（最低成本补丁）:
```css
@media (max-width: 768px) {
  .app { flex-direction: column; }
  .sidebar { width: 100%; height: auto; }
  .detail-layout { grid-template-columns: 1fr; }
  .app-footer { flex-direction: column; gap: 4px; text-align: center; }
}
```
对照参考: `saas-admin.html` 已经完整实现了 `@media (max-width: 900px/600px/768px)`，可直接复制其 CSS 模式到这 3 个文件。
