# ISO 22000 / FSSC 22000 食品安全管理体系

> 本文件整理与贵公司食品安全管理体系相关的ISO标准和FSSC认证要求。

---

## 一、ISO 22000:2018 食品安全管理体系

### 1.1 概述

ISO 22000是国际标准化组织发布的食品安全管理体系标准，适用于食品链中的所有组织。2018版采用了高阶结构（HLS），便于与其他管理体系（如ISO 9001）整合。

### 1.2 核心框架（PDCA循环）

**策划（Plan）**：
- 确定食品安全方针和目标
- 识别食品安全危害和控制措施
- 建立前提方案（PRP）和操作性前提方案（OPRP）
- 建立HACCP计划

**实施（Do）**：
- 实施前提方案和HACCP计划
- 建立沟通机制（内部和外部）
- 应急准备和响应
- 能力、培训和意识

**检查（Check）**：
- 监视和测量
- 内部审核
- 管理评审
- 验证和确认

**改进（Act）**：
- 不符合和纠正措施
- 持续改进

### 1.3 关键条款

| 条款 | 内容 | 贵公司实施要点 |
|------|------|--------------|
| 4 | 组织环境 | 识别相关方需求、确定体系范围 |
| 5 | 领导作用 | 最高管理者承诺、食品安全方针 |
| 6 | 策划 | 风险和机遇的应对措施、食品安全目标 |
| 7 | 支持 | 资源、能力、意识、沟通、文件化信息 |
| 8 | 运行 | OP/HACCP计划、可追溯性、应急准备 |
| 9 | 绩效评价 | 监视测量、内部审核、管理评审 |
| 10 | 改进 | 不符合、纠正措施、持续改进 |

## 二、FSSC 22000

### 2.1 概述

FSSC 22000（Food Safety System Certification 22000）是基于ISO 22000的食品安全认证方案，获得GFSI（全球食品安全倡议）认可。

### 2.2 与ISO 22000的关系

```
FSSC 22000 = ISO 22000 + 行业特定PRP标准（如ISO/TS 22002-1）+ FSSC附加要求
```

### 2.3 行业特定PRP标准

| 标准 | 适用行业 |
|------|---------|
| ISO/TS 22002-1 | 食品制造 |
| ISO/TS 22002-2 | 餐饮 |
| ISO/TS 22002-4 | 食品包装制造 |
| ISO/TS 22002-6 | 饲料和动物食品制造 |

### 2.4 FSSC附加要求

- 食品安全文化建设
- 食品防护（Food Defense）
- 食品欺诈预防（Food Fraud）
- 环境监控计划
- 过敏原管理
- 产品设计和开发

## 三、ISO 9001:2015 质量管理体系

### 3.1 与食品安全管理体系的关系

- ISO 9001关注产品质量和客户满意度
- ISO 22000关注食品安全
- 两者可以整合运行，共享文件控制、内审、管理评审等要素

### 3.2 贵公司适用条款

- 质量方针和目标
- 过程方法和风险思维
- 资源管理
- 产品实现（设计开发、采购、生产）
- 监视、测量、分析和改进

## 四、TL 9000 通讯行业质量管理体系

### 4.1 概述

TL 9000是通讯行业专用质量管理体系标准，基于ISO 9001增加了通讯行业的特定要求。

### 4.2 贵公司相关性

- 贵公司产品（ARA/DHA）的下游客户（婴幼儿配方奶粉企业）的供应链可能涉及TL 9000要求
- 光通讯模块行业客户可能要求供应商满足TL 9000

## 五、认证维护要点

### 5.1 年度监督审核

- 每年一次外部审核
- 审核范围覆盖体系全部要素
- 不符合项需在规定时间内关闭

### 5.2 再认证审核

- 每三年一次全面再认证
- 体系运行三年的有效性评估

### 5.3 内部审核

- 每年至少一次全面内审
- 审核员需具备资质和独立性
- 审核结果输入管理评审
