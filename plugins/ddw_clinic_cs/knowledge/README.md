# 口腔客服知识库维护说明

## 目录结构

- `clinic_basic.md` — 门诊基础信息（地址、电话、营业时间）
- `clinic_faq.md` — 常见问答（预约、医保、洗牙等）
- `clinic_emergency.md` — 应急处理指导（牙痛、出血、外伤）
- `clinic_postop.md` — 术后注意事项（拔牙、根管、种植）

## 维护规则

1. 所有医学内容需经医生校对后再去掉【待医生校对】标记
2. 【待补充】占位内容需补充完整后去掉标记
3. 新增知识文件放入本目录，支持 `.md` / `.yaml` / `.txt` / `.json` 格式

## 红线声明（最高优先级）

- **禁止录入任何价格/费用数字**（防同行套价）
- **禁止录入患者个人信息**（隐私保护）
- **禁止录入医生个人隐私信息**
- **禁止推荐具体药物名称和剂量**（需遵医嘱）
