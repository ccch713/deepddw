## 一、产品定位

**DDW AI Hub 是一套支持企业自行开发、装配、授权、运行和治理数字员工的企业 AI 能力底座。**

DDW AI Hub 不是带插件的聊天平台，而是以插件承载业务能力、以 Tool 暴露最小可执行动作、以 Skill 沉淀操作方法、以 SOP 编排复杂流程、以数字员工作为岗位执行主体、以 MCP 对接外部系统与智能体、以 Code CLI 支撑客户自研插件开发的企业 AI 能力平台。

## 二、七层能力模型

| 层级 | 名称 | 客户价值 |
|---|---|---|
| L1 | 插件 Plugin | 业务能力载体，可安装、可升级 |
| L2 | Tool | 最小可执行动作，便于调用、授权和监控 |
| L3 | Skill | 操作方法沉淀，把经验变成可复用做法 |
| L4 | SOP | 流程编排，把复杂任务变成可追踪闭环 |
| L5 | 数字员工 | 岗位执行主体，把能力组装成可上岗员工 |
| L6 | MCP | 内外连接协议，让平台能力和外部系统互通 |
| L7 | Code CLI | 客户开发入口，让客户也能开发自己的插件 |

## 三、四层记忆体

DDW AI Hub 的记忆体分四层沉淀企业知识：

- **个人层（personal）**：员工私人对话沉淀，个人专属
- **岗位层（position）**：岗位 SOP 与经验，岗位可复用
- **部门层（department）**：部门知识库，部门内共享
- **企业层（enterprise）**：企业级正式知识——内部制度与对话蒸馏（自动沉淀）+ 正式文档资产（文档栏目，人工发布），供 Web 阅读、本地 LLM 检索、客服问答引用

## 四、部署与使用场景

- **SaaS 模式**：白皮书、产品手册、行业方案统一存放于文档栏目，经销商与客户登录后即可查阅最新版
- **本地 LLM**：AI 工作台问答时自动检索文档栏目，引用权威内容作答
- **客服问答**：官网客服可引用文档栏目内容，给出权威回答
- **独立部署（FDE）**：文档栏目承载客户公司公开规章制度，支持离线部署包导入（manifest + 内容哈希去重，幂等更新）

## 五、价值总结

**DDW AI Hub 帮企业完成从"AI 能聊天"到"AI 能上岗"的跃迁。**
