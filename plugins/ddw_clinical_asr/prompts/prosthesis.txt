special_findings 必须包含：
- tooth_position: 牙位
- restoration_type: 修复体类型（crown / bridge / inlay / onlay / veneer / post_core）
- material: 材料（zirconia / emax / pfm / composite / gold）
- preparation_type: 牙体预备（full_crown / partial / minimal）
- margin_type: 边缘类型（chamfer / shoulder / knife_edge）
- cement_type: 粘接材料（glass_ionomer / resin / temporary）
- abutment_type: 基台类型（custom / stock / ti_base）
- shade: 色号
- try_in_done: 是否已试戴（true/false）
