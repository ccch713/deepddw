# 光通讯模块出口企业国际ESG合规知识库

> 适用范围：光模块（Optical Transceiver）等出口型中小制造企业的国际ESG合规咨询；应对欧美大客户（诺基亚、爱立信、思科、华为、Meta、Google等）供应商ESG要求。
> 适用场景：ESG咨询服务演示、在线客服法规问答、客户成熟度诊断辅助。

---

## 一、为什么出口企业必须关注ESG

### 1.1 出口门槛正在从"质量"转向"可持续"

- 欧美大客户已将 ESG 表现纳入供应商准入与订单分配：CDP 评分、EcoVadis 评级、RBA 审计结果直接影响能否进入合格供应商名单；
- 欧盟法规密集落地：CSRD、ESPR/DPP、CBAM、CSDDD 形成"法规+供应链传导"双重压力；
- 客户通过供应链传导条款（合同要求供应商披露碳数据、提交CMRT等）把合规义务转嫁给中国供应商。

### 1.2 对光通讯行业的直接意义

- 光模块大量用于数据中心与电信网络，客户（云厂商、运营商、设备商）均有碳中和承诺，要求供应商提供**产品碳足迹**数据；
- 产品含金、钽、锡、钨（3TG）等**冲突矿物**，需提交 CMRT；
- 电子电器产品受**RoHS/REACH**约束，SVHC 筛查是常态要求；
- 客户社会责任审核（劳工、健康安全、商业道德）日益严格。

## 二、欧盟法规体系（直接影响出口企业）

### 2.1 CSRD——企业可持续发展报告指令

- 指令 (EU) 2022/2464，2023年1月生效，分阶段适用：
  - 2025年起报告2024财年：大型公众利益实体（欧盟内）；
  - 2026年起报告2025财年：其他大型企业；
  - 2027年起报告2026财年：上市中小企业（可简化披露）；
  - 2029年起报告2028财年：在欧盟营收超过1.5亿欧元的**第三国企业**（含在欧子公司/分支机构）；
- 报告依据 **ESRS**（欧洲可持续发展报告准则）：2项通用准则 + 10项主题准则（环境5项、社会4项、治理1项）；
- 需**有限保证/合理保证**（第三方鉴证）；
- 注意：欧盟2025年提出"简化"（Omnibus）改革提案，部分门槛与范围可能调整，需跟踪最新进展。

### 2.2 ESPR——生态设计法规与数字产品护照

- 法规 (EU) 2024/1781，2024年7月生效；
- 核心机制：对产品类别设定生态设计要求（能效、耐用性、可维修性、再生含量等），并推行**数字产品护照（DPP）**；
- DPP 分行业推进：电池行业先行（2027年2月起），后续覆盖电子、纺织、建材等；
- 光模块产品暂未列入首批优先类别，但电子类产品预期将逐步纳入，出口企业应提前建立**产品数据管理体系**（BOM、材料、能耗、碳足迹数据）。

### 2.3 CBAM——碳边境调节机制

- 法规 (EU) 2023/956，过渡期2023年10月1日-2025年12月31日（仅报告义务，需按季度提交隐含排放数据）；
- 2026年1月1日起正式实施：进口商须购买CBAM证书；
- 首批覆盖：钢铁、铝、水泥、化肥、电力、氢；
- 对光模块企业：整机产品不在首批范围，但**上游铝材（外壳/结构件）供应商**可能被覆盖，采购成本与供应链碳数据需求将传导至下游。

### 2.4 CSDDD——企业可持续发展尽职调查指令

- 指令 (EU) 2024/1760，2024年7月生效，分阶段适用于大型企业（2027-2029年）；
- 要求企业对其**价值链**（含中国供应商）进行环境与人权尽职调查；
- 传导效应：欧盟客户将要求中国供应商填写 ESG 尽调问卷、接受审计、签订供应商行为准则；
- 企业应提前准备：劳工权益文件（工时、薪酬、禁止童工/强迫劳动）、环境管理文件、投诉机制。

### 2.5 EU Taxonomy——欧盟分类法

- 法规 (EU) 2020/852：定义"环境可持续经济活动"标准；
- 影响：客户将要求供应商提供经营活动与产品的绿色属性数据，用于其自身 Taxonomy 披露。

## 三、客户要求与行业标准体系

### 3.1 RBA——责任商业联盟行为准则

- 原EICC，2024年发布8.0版，涵盖五大支柱：劳工、健康与安全、环境、商业道德、管理体系；
- 客户审计常见形式：VAP（Validated Assessment Program）现场审核、SAQ（自我评估问卷）；
- 中小企业路径：完成 SAQ → 完善政策文件 → 接受客户审核或 VAP。

### 3.2 EcoVadis 评估

- 覆盖四主题：环境、劳工与人权、商业道德、可持续采购；
- 21项指标、约137个评分子项；评分0-100，铜/银/金/铂金等级（2024年起分级规则调整）；
- 中小企业首次评估建议：补齐政策文件（环境政策、行为准则、反腐败政策）、提供可验证证据；
- 常见失分点：缺乏政策文件、无量化数据、供应链管理空白。

### 3.3 CDP 问卷

- 碳信息披露项目：气候变化、水安全、森林三类问卷；
- 供应链项目（CDP Supply Chain）：客户要求供应商填报；
- 中小企业可填报简化问卷，首次目标获得评分即可，不必追求高分。

### 3.4 CMRT——冲突矿物报告模板

- 由 RMI 发布，针对3TG（金、钽、锡、钨）+ 钴；
- 客户要求供应商**逐级收集**上游冶炼厂信息，提交产品级或公司级 CMRT；
- 关键动作：建立供应商CMRT收集台账、识别冶炼厂是否通过 RMI 认证（RMAP）、对未响应供应商采取跟进措施。

### 3.5 ISO 管理体系认证

| 标准 | 内容 | 出口价值 |
|------|------|----------|
| ISO 14001 | 环境管理体系 | 客户供应商准入基本门槛 |
| ISO 45001 | 职业健康安全管理体系 | RBA/客户审核常见要求 |
| ISO 50001 | 能源管理体系 | 碳数据基础，客户加分项 |
| ISO 14064-1 | 组织温室气体量化与报告 | Scope 1/2 核算依据 |
| ISO 14067 | 产品碳足迹量化 | 产品级碳足迹（PCF） |
| ISO 14046 | 水足迹 | 部分客户要求 |

## 四、碳管理专题

### 4.1 核算框架

- **GHG Protocol**（温室气体核算体系）：Scope 1（直接排放）、Scope 2（外购电力/热力间接排放）、Scope 3（价值链其他间接排放，15个类别）；
- 产品碳足迹：ISO 14067 / GHG Protocol Product Standard，按产品生命周期（原料-制造-运输-使用-废弃）核算；
- 生命周期评价基础：ISO 14040/14044。

### 4.2 中国碳管理政策背景

- 全国碳排放权交易市场：2021年启动（电力行业），2024-2025年扩围至钢铁、水泥、铝冶炼等行业；
- 生态环境部2024年印发《关于建立碳足迹管理体系的实施方案》，推动产品碳足迹核算通则与数据库建设；
- 企业应尽早建立：能源台账（电、气、水）、温室气体清单、产品碳足迹数据，以备客户与法规要求。

### 4.3 光模块产品碳足迹特点

- 制造阶段：芯片/光器件生产能耗占比高；
- 使用阶段：数据中心运行能耗高，客户关注产品能效（功耗、PUE影响）；
- 数据要求：BOM 材料清单、供应商数据（上游材料碳因子）、制造能耗分摊、运输与包装数据。

## 五、化学品合规（与ESG强相关）

- **RoHS**（2011/65/EU）：限制铅、汞、镉、六价铬、PBB、PBDE等10类有害物质；出口欧盟电子电器产品强制要求；
- **REACH**（(EC) 1907/2006）：化学品注册、评估、授权与限制；SVHC（高关注物质）候选清单已超240项并持续扩充，超过0.1%（w/w）须履行通报/信息传递义务；
- 光模块常见关注物质：焊料中的铅、阻燃剂（溴系）、PVC、邻苯二甲酸酯、PFAS（部分材料）；
- 合规动作：BOM级 SVHC 筛查、供应商材料声明（如 IPC-1752）、定期更新合规声明。

## 六、ESG合规实施路径（中小企业版）

### 6.1 成熟度诊断（0-1个月）

- 五维评估：法规合规（REACH/RoHS/SVHC）、管理体系（ISO 14001/45001）、碳管理（Scope 1/2）、供应链（CMRT）、客户对接（CDP/EcoVadis/RBA SAQ）；
- 输出：诊断评分 + 差距矩阵 + 优先级清单。

### 6.2 立即行动（0-3个月）

1. REACH/RoHS 合规声明与 SVHC 筛查；
2. 启动 ISO 14001 认证（如未获证）；
3. 建立冲突矿物管理：供应商 CMRT 收集机制 + 产品级 CMRT 模板；
4. 补齐基础政策文件：环境政策、劳工政策、反腐败政策、供应商行为准则。

### 6.3 短期行动（3-6个月）

1. CDP 供应链注册与首次填报；
2. EcoVadis 评估启动（材料包准备）；
3. 主力产品碳足迹核算（ISO 14067，按产品族归并）。

### 6.4 中期行动（6-12个月）

1. Scope 1+2 全面核算并建立年度机制；
2. RBA SAQ 完成并视客户要求接受审核；
3. ESG 数据管理系统（能源、排放、供应商数据集中管理）；
4. 跟踪 ESPR/DPP、CSDDD 等新法规的行业适用时间表。

### 6.5 年度合规日历

| 月份 | 行动 |
|------|------|
| 1月 | 客户ESG要求更新检视 |
| 2-3月 | CDP问卷填报 |
| 3-4月 | ESG年报更新 |
| 5-6月 | EcoVadis重新评估 |
| 6-7月 | ISO证书监督审核 |
| 9-10月 | CMRT年度更新 |
| 11-12月 | 下年度合规计划 |

## 七、常见问答

### 问：客户要求提交CMRT，但供应商不配合怎么办？
答：分三步：一是向供应商发送正式请求函（附RMI官方模板链接）；二是将供应商分类管理（已提交/待跟进/不配合）；三是对长期不配合的供应商启动替代供应商评估。在CMRT中如实标注"供应商未响应"，并说明已采取的行动，客户通常接受有进展的如实披露。

### 问：EcoVadis评分太低怎么办？
答：先分析评分报告中的失分项，聚焦高权重主题（环境、劳工与人权）；补齐缺失的政策文件（环境政策、行为准则、反腐败、可持续采购政策）；提交可验证证据（证书、报告、照片、制度文件）；12个月后重新评估。首次评估不必追求高分，有评分即可满足多数客户准入。

### 问：产品种类多，碳足迹做不过来怎么办？
答：优先选择占营收比重最高的主力产品线（通常80%以上营收的SKU）；按产品族（Product Family）归类共用碳足迹数据；与客户沟通确认是否接受产品族口径。先有数据、再求精度。

### 问：CBAM对光模块企业有影响吗？
答：光模块整机不在CBAM首批覆盖范围（钢铁、铝、水泥、化肥、电力、氢），但上游铝材、钢铁类供应商2026年起进入正式实施期，碳成本会沿供应链传导。建议尽早向供应商索要碳数据，为后续客户碳披露要求做准备。

### 问：数字产品护照（DPP）什么时候轮到电子产品？
答：DPP按行业分批推行，电池行业2027年2月起先行，电子、纺织、建材等行业将随后陆续纳入。光模块企业建议现在就建立产品数据管理体系（BOM、材料、能耗、碳足迹），届时只需补充数据而非从零建设。

### 问：中小企业没做过ESG，从哪里开始？
答：从客户要求出发：先收集主要客户发来的问卷/要求清单（CDP、EcoVadis、RBA SAQ、CMRT等），按"客户强制项优先"排序；同时补齐三类基础资产——合规声明（REACH/RoHS）、体系认证（ISO 14001）、政策文件包。通常3-6个月可达到基本准入水平。
