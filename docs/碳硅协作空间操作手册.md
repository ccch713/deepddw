# 碳硅协同 · 操作手册 v1.1

> 适用版本：ddw_flow_designer ≥ 1.0.0（2026-08-11）
> 入口：DDW 控制台 → 碳硅协同（或直接访问 /carbon-silicon.html）

---

## 一、碳硅协同是什么

碳硅协同是 DDW 的**零代码流程设计器**：不写代码，通过拖拽节点、连线，就能编排"数字员工 + Skill"的协作流程。适合业务人员设计：投诉处理、审批流转、数据加工等 AI 协作链路。

**一句话**：把"谁先做什么、什么条件走哪条路、哪些事可以同时做"画成一张图，DDW 按图自动执行。

## 二、四个页面

| 页面 | 用途 |
|------|------|
| 流程列表 | 查看/编辑/执行/启用停用/删除所有流程 |
| 公司看板 | 全公司流程统计（只读）：总数/启用数/执行次数/平均耗时 |
| 审核 | 跨部门流程的待审列表，通过/拒绝 |
| 新建流程 | 进入拖拽编辑器 |

## 三、节点类型（7 种）

| 节点 | 图标 | 作用 | 配置项 |
|------|------|------|--------|
| 开始 | ▶️ | 流程入口，接收外部输入 | 无（输入在"执行"时填写） |
| 数字员工 | 🤖 | 调用某数字员工能力 | 名称 + 执行指令（Prompt） |
| Skill | ⚡ | 调用某技能 | 名称 + 执行指令（Prompt） |
| 条件判断 | 🔀 | 按条件走不同分支 | 条件表达式（见下） |
| 并行 | 🔗 | 多条分支同时执行 | 出边自动并行 |
| 合并 | ⚡ | 等待所有并行分支完成后汇聚 | 无 |
| 结束 | ⏹️ | 流程出口 | 无 |

**条件表达式语法**（零代码、无需 LLM 判断，确定性强）：
- `contains:关键词` → 输入文本包含关键词则走 yes 分支
- `not contains:关键词` → 不包含则走 yes 分支
- 留空 → 输入非空则走 yes 分支

**连线分支标签**：选中节点后，属性面板底部显示"下游连线分支"下拉，可把每条连线标为 **yes / no / 默认**。条件节点根据判断结果选择带对应标签的连线。

## 四、操作步骤

### 1. 新建流程
1. 顶部导航 → **＋ 新建流程**
2. 从左侧面板**拖拽节点**到画布
3. 点击节点 → 右侧属性面板填写**名称**和**执行指令**
4. 点击节点右上角 **↗**（连线模式）→ 再点击目标节点完成连线
5. 点 **×** 删除节点；节点可拖动调整位置
6. 点 **保存草稿**（未保存直接离开会丢失）

### 2. 发布流程
- 点 **发布** → 选择作用域：
  - **部门级**：直接发布，立即生效
  - **跨部门**：输入需审核的部门 ID（逗号分隔，留空=公司级单审）→ 进入"待审核"
- 版本号自动递增：首次 v1.0.0，之后 v1.1.0、v1.2.0……

### 3. 执行流程
- 列表页点 **执行**（或编辑器内点执行）
- 系统按节点顺序调用 LLM 网关：每个节点的"执行指令 + 上游输出"作为输入
- 条件节点按表达式选路；并行节点分支同时执行；合并节点等待全部分支完成后汇聚
- 执行结果逐节点展示（每次执行记录到执行历史）

### 4. 审核流程（跨部门）
1. 流程列表出现"待审核"状态
2. 顶部导航 → **审核** 页
3. 逐条 **通过 / 拒绝**（可填意见）
4. **所有部门都通过** → 自动发布生效；任一拒绝 → 退回草稿

### 5. 启用/停用/删除
- **启用**：仅已发布/待审核流程可启用
- **停用**：立即停止，状态变"已停用"
- **删除**：仅"已停用 ≥ 12 个月"的流程可删除（公司管理员）

## 五、常见场景 5 例

### 场景 1：客户投诉分级处理（条件分支）
```
开始 → 条件判断(contains:紧急) ─yes→ 紧急处理A → 合并 → 结束
                             └no→ 普通处理 ────┘
```
- 条件节点：名称"是否紧急"，表达式 `contains:紧急`
- 紧急出边标 yes，普通出边标 no

### 场景 2：多路并行调研（并行 + 合并）
```
开始 → 并行 ─┬→ 技术调研
             ├→ 市场调研
             └→ 合规调研
        合并 ←──┴──────
结束 ←─────
```
- 并行节点出边自动同时执行；合并节点汇总三路结果

### 场景 3：日报自动生成
```
开始 → Skill(数据整理: 把输入整理成要点) → Skill(日报生成: 按要点生成日报) → 结束
```

### 场景 4：合规双人复核（跨部门）
```
开始 → Skill(合同摘要) → 并行 ─┬→ 法海(合规审查)
                              └→ 财务小助手(财务审查)
                      合并 → 结束
```
- 发布选**跨部门**，审核部门填合规部、财务部 ID → 两部门管理员都通过后生效

### 场景 5：质量投诉闭环（含条件兜底）
```
开始 → Skill(投诉分类) → 条件(contains:赔偿) ─yes→ 客服小助手(安抚+赔偿方案) → 合并 → 结束
                                          └no→ 普通回复 ───────────────────┘
```

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 节点拖不进去 | 左侧面板节点按住拖到画布松开（不要点） |
| 条件分支没生效 | 检查条件表达式格式 + 连线是否标了 yes/no 标签 |
| 合并只显示 1 个分支 | 确认并行/条件多分支已连线到合并节点，且分支节点已保存 |
| 发布提示"请先保存" | 新建流程先点保存草稿再发布 |
| 执行报"流程未启用" | 先发布并启用流程 |
| 删除按钮不出现 | 仅"已停用"流程可删，停用不满 12 个月不显示 |

## 七、权限说明（v1.1）

| 操作 | 成员 | 部门管理员(admin) | 公司管理员(owner) |
|------|------|-----------------|------------------|
| 创建/编辑自己的流程 | ✅ | ✅ | ✅ |
| 发布 | ✅ | ✅ | ✅ |
| 审核跨部门流程 | ❌ | ✅ | ✅ |
| 启用/停用 | ✅（自己的） | ✅ | ✅ |
| 删除（停用≥12月） | ❌ | ❌ | ✅ |
| 公司看板 | ❌ | ✅ | ✅ |

> 注：部门级管理员与部门的绑定关系，待组织员工体系（ddw_org）接通后细化；当前 admin 角色可审全部待审流程。
