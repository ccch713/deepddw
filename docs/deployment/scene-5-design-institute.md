# DDW 设计院智能解决方案 · 设计院场景部署手册

> 场景：设计院（建筑设计/市政设计/工业设计）全流程智能化
> 目标用户：设计院 IT 管理员/院长
> 硬件要求：服务器 / Mac mini M4 32G / 云主机
> 部署方式：内网部署（数据不出院）

---

## 一、场景描述

设计院需要：
1. 设计人员资质证书管理（注册建筑师/结构师/设备师等）
2. 投标标书智能撰写（技术标/商务标）
3. 历史造价知识库（积累项目造价数据）
4. 多风格投标书生成（同一项目多版本差异化）
5. 造价估算辅助（基于历史数据）

## 二、需要启用的插件

| 插件 | 用途 | 启用方式 |
|------|------|---------|
| ddw-personnel-qual | 核心：资质证书管理+到期预警+投标人员匹配 | ✅ 必须启用 |
| ddw-bid-writer | 核心：标书撰写+多风格修饰+合规检查 | ✅ 必须启用 |
| ddw-cost-knowledge | 重要：造价知识库+自然语言查询+估算辅助 | ✅ 推荐启用 |
| ddw_training | 辅助：新员工培训（可选） | ⚡ 可选 |
| ddw-smart-cs | 辅助：AI 对话界面 | ✅ 必须启用 |

## 三、部署步骤

### 3.1 安装 DDW AI Hub

```bash
# 下载安装包
curl -L https://ddw.9cio.com/install.sh | bash

# 启动服务
ddw start --port 8500
```

### 3.2 配置本地 LLM

```bash
# 32G 设备推荐 14B 模型（造价知识库提炼需要更强的模型）
ollama pull qwen2.5:14b

ddw config set llm.provider ollama
ddw config set llm.model qwen2.5:14b
ddw config set llm.endpoint http://localhost:11434
```

### 3.3 启用插件

```bash
ddw plugin enable ddw-personnel_qual
ddw plugin enable ddw-bid-writer
ddw plugin enable ddw-cost-knowledge
ddw plugin enable ddw-smart-cs
ddw restart
```

### 3.4 初始化资质管理

```
帮我初始化设计人员资质管理：

1. 导入全院持证人员名单
2. 设置证书类型：一级注册建筑师、二级注册建筑师、一级注册结构工程师、
   二级注册结构工程师、注册设备工程师（暖通/给排水/电气）、
   注册监理工程师、注册造价工程师、注册咨询工程师
3. 设置到期预警：提前 90/60/30/7 天分级提醒
4. 开启挂证风险检测
```

### 3.5 导入资质数据

准备 Excel 文件（含姓名/证书类型/证书编号/有效期等），在对话框中：

```
请导入资质证书数据：~/ddw-data/资质证书清单.xlsx
```

### 3.6 初始化造价知识库

```
请扫描以下目录的历史造价文件，提炼为知识库：

目录：~/ddw-data/cost-projects/
文件格式：Excel 预算表、PDF 结算报告、广联达导出文件

提炼内容：
1. 项目基本信息（名称/类型/面积/地点/年份）
2. 分部分项工程量清单
3. 材料价格信息
4. 综合单价和合价
```

### 3.7 导入历史造价文件

```bash
mkdir -p ~/ddw-data/cost-projects/

# 将历史造价文件复制到该目录
cp -r ~/造价文件/2023年/*.xlsx ~/ddw-data/cost-projects/
cp -r ~/造价文件/2024年/*.xlsx ~/ddw-data/cost-projects/
cp ~/造价报告/*.pdf ~/ddw-data/cost-projects/
```

### 3.8 配置投标书模板

```
请创建设计院投标书标准模板：

技术标模板：
1. 项目概述与理解
2. 设计理念与方案
3. 技术路线与方法
4. 实施计划与进度
5. 质量控制措施
6. 风险管理方案
7. 项目团队介绍

商务标模板：
1. 企业资质与业绩
2. 项目报价说明
3. 服务承诺

请将模板保存到系统中。
```

## 四、日常使用

### 4.1 资质管理

#### 查询证书状态

```
查看全院证书健康状态。
```

#### 投标人员匹配

```
有一个项目需要：一级注册建筑师 1 名 + 一级注册结构工程师 1 名
+ 注册设备工程师（暖通）1 名，请推荐可用人员。
```

#### 到期预警

```
查看即将到期（30天内）的证书列表。
```

### 4.2 标书撰写

#### 上传招标文件

```
请解析这份招标文件：~/投标文件/某项目设计招标文件.pdf
提取评分标准、资质要求、技术参数、废标条款。
```

#### 生成标书

```
根据解析结果，生成技术标初稿。
```

#### 多风格修饰

```
将生成的标书进行风格修饰：
- 措辞风格：保守型
- 章节结构：调整
- 图表排版：调整
生成一个修饰后的版本。
```

#### 合规检查

```
对这份标书进行合规检查。
```

### 4.3 造价知识库

#### 自然语言查询

```
类似商业综合体项目，暖通工程占比通常是多少？
```

#### 造价估算

```
我有一个新项目：武汉市某住宅小区，建筑面积 8 万㎡，
框架剪力墙结构，精装修交付。请基于历史数据估算造价。
```

#### 材料价格查询

```
查询 2024 年武汉市 C30 混凝土的价格趋势。
```

### 4.4 招投标全流程

```
完整投标流程：

1. 上传招标文件
2. 解析评分标准
3. 匹配投标人员
4. 生成技术标
5. 生成商务标
6. 合规检查
7. 生成差异化版本
8. 导出 Word 文档
```

## 五、配置参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| llm.model | qwen2.5:14b | 32G 设备推荐 |
| personnel_qual.expiry_warn_days | 90,60,30,7 | 分级预警 |
| bid_writer.default_doc_type | 技术标 | 默认标书类型 |
| bid_writer.available_styles | 标准/保守/激进/创新型 | 风格选项 |
| cost_knowledge.estimate_threshold | 0.6 | 估算相似度阈值 |
| cost_knowledge.max_results | 20 | 查询最大结果数 |

## 六、注意事项

1. **数据安全**：工程图纸/造价数据/投标文件属商业机密，必须内网部署
2. **模型选择**：造价知识库提炼需要较强的语言理解能力，推荐 14B 以上模型
3. **文件格式**：广联达导出文件（.gbq/.gccp）需要专门解析，建议先转为 Excel
4. **人员匹配**：投标人员匹配需要准确的证书数据，建议定期更新
5. **标书质量**：AI 生成的标书需要人工审核后才能提交
6. **多风格功能**：风格修饰功能用于企业内部版本管理，确保各版本差异化
