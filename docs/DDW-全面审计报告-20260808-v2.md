### 3.3 F821 详情 (唯一P0)

```
core/hris_adapters/feishu.py:61 — Undefined name `httpx`
```
**根因**: 返回类型注解用了 `httpx.AsyncClient`，但 `httpx` 未在顶部导入（延迟导入在函数体内）。  
**风险**: 低 — 已有 `# type: ignore[name-defined]` 注释，运行时不触发（类型注解仅静态分析用）。  
**修复**: 在文件顶部加 `from typing import TYPE_CHECKING` + `if TYPE_CHECKING: import httpx`。

### 3.4 一键自动修复建议

# 可安全自动修复的 (899项)

| 限流 | ⚠️ 用函数属性 `_last` 做内存限流 — 多worker下失效 |
