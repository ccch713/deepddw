建议采用的产品定位

DDW AI Hub 是以插件为业务能力载体，以 Tool 为最小可执行能力，以 Skill 为操作方法，以 SOP 为流程编排，以数字员工为执行主体，以 MCP 为内外连接协议，以 Code CLI 为客户开发入口的企业 AI 能力平台。

客户易懂长期可扩展可直接放官网

这条定位比“带插件的AI聊天平台”更准确，也更能支撑未来客户自研、授权治理、数字员工、MCP 和 Code CLI 的增长。

落地顺序建议

P0 先建真实平台底座统一对象定义、能力注册中心、权限与信任模型、客户自研插件签名/审核、静态页面去数组化
P1 再补连接层真实Skill后端、双向MCP、Code CLI开发者中心、安装/测试/审计链、租户授权联动
P2 最后做体验层数字员工模板化、SOP运行器、人工接管、Trace与质量评价、多渠道统一体验
